BIOL 110 Exam Practice
Version 1.0.3 (Stable)
23 July 2026

========================================
NEW FEATURES
========================================

• Added automatic category statistics tracking.
  - Categories are now generated dynamically from the question bank.
  - Eliminates the need to manually update category performance tracking when new topics are added.

• Added category performance reporting at quiz completion.
  - Students now receive category-by-category performance summaries.
  - Displays correct responses, total responses, and percentage correct for each category attempted.

• Added balanced question selection when "All Categories" is chosen.
  - Ensures broader topic representation across quizzes.
  - Reduces overrepresentation of heavily populated question categories.

• Added anonymous question-level analytics.
  - Student responses are transmitted anonymously to a Google Sheets database.
  - Captures:
      * Question attempted
      * Category
      * Exam
      * Difficulty
      * Selected answer
      * Correct/incorrect status
  - Facilitates instructional analytics and question refinement.

========================================
ACCESSIBILITY IMPROVEMENTS
========================================

• Added Dyslexia-Friendly Font Mode.
  - Toggle enables OpenDyslexic font for improved readability.
  - Includes enhanced spacing and readability optimizations.

• Added Reduced Animation Mode.
  - Disables fade animations and transition effects.
  - Provides a more comfortable experience for students sensitive to motion effects.
  - Question transitions become instantaneous when enabled.

========================================
USER EXPERIENCE IMPROVEMENTS
========================================

• Improved category statistics initialization and reset behavior.

• Improved quiz startup logic.

• Removed redundant question-loading behavior.

• Refined review mode integration.

• Improved compatibility with future category and question-bank expansion.
